\begin{abstract}
Clinicians need fast help to judge DNA variants. A single base change can be harmless. It can also raise disease risk. Current rules need manual review. They do not scale to rare variants. This paper presents a deployed web system. The system uses the Evo2-7B genomic language model. It scores substitutions, deletions, insertions, and delins. It shows a clear prediction and a confidence value. The front end uses Next.js. It gets reference data from UCSC and NCBI. The back end uses a Modal H100 GPU. It runs one authenticated endpoint. The system centers an 8192-bp window on the variant. It scores the reference and the variant. It computes a delta score. It compares the delta to a BRCA1 threshold. The threshold is $\tau=-0.000918$. A 500-variant BRCA1 set gives AUROC near 0.73. This result agrees with published zero-shot results. The main value is practical. The paper gives a full pipeline. It goes from public genome data to GPU scoring. It lists limits in clear words.
\end{abstract}

\section{Introduction}
\IEEEPARstart{D}{NA} uses four letters: A, C, G, and T. The human genome has about 3 billion letters. Most changes do not cause disease. A few changes do cause disease. The task is to tell them apart.

Hospitals use population data and expert rules. The ACMG guide is one example~\cite{richards2015acmg}. Experts also use tools such as SIFT~\cite{ng2003sift}, PolyPhen-2~\cite{adzhubei2010polyphen}, and CADD~\cite{kircher2014cadd}. These tools help. They still need feature design. They miss many rare variants.

Language models learn from raw sequence. Protein models include ESM-2~\cite{lin2023esm} and AlphaMissense~\cite{cheng2023alphamissense}. DNA models include Nucleotide Transformer~\cite{dalla2023nucleotide}, Enformer~\cite{avsec2021enformer}, Borzoi~\cite{linder2023borzoi}, Evo~\cite{nguyen2024evo}, and Evo2~\cite{brixi2025evo2}. Evo2 learns next-base prediction. It uses up to 1M context. It trains on OpenGenome2. It shows zero-shot skill on \textit{BRCA1}.

Most Evo2 demos stay in notebooks. This work moves the model to a web app. A user selects an assembly. The user finds a gene. The user views sequence and ClinVar data. The user then requests a score. The system returns a delta, a call, and a confidence value.

This paper makes four claims:
\begin{itemize}
\item It describes a live stack: UCSC~\cite{kent2002ucsc,lee2022ucsc}, NCBI E-utilities, ClinVar~\cite{landrum2014clinvar,landrum2023clinvar}, Next.js~\cite{nextjs2024}, Modal H100, and FastAPI~\cite{fastapi2024}.
\item It defines scoring for four types: SNV, deletion, insertion, and delins. It uses one window size. It uses one delta rule.
\item It shows calibration on 500 \textit{BRCA1} variants. It uses ROC analysis~\cite{hanley1982roc} and Youden's index~\cite{youden1950index}.
\item It lists limits. It flags indel calls as provisional. It notes assembly drift and API caps.
\end{itemize}
The text follows ASD-STE100 rules for clear English. It uses short sentences. It uses active voice. It uses one idea per sentence.

\section{Background}
DNA has two strands. A pairs with T. G pairs with C. One strand is enough for the model. Chromosomes hold the full string. Genes hold exons and introns. Promoters mark start sites. Enhancers can act from far away. They touch genes through DNA loops. Long context thus matters.

Alignment methods form the base~\cite{needleman1970general,smith1981comparison}. Fast search follows~\cite{altschul1990blast}. Sequencing Removal follows Sanger~\cite{sanger1977dna}. ClinVar stores variant meaning~\cite{landrum2014clinvar}. Our system adds a model view. It does not replace curation.

\section{Related Work}
Early tools use conservation. SIFT scores residue change~\cite{ng2003sift}. PolyPhen-2 adds structure~\cite{adzhubei2010polyphen}. CADD joins many signals~\cite{kircher2014cadd}. ACMG joins evidence types~\cite{richards2015acmg}.

Protein language models remove hand features. ESM-2 scales evolution data~\cite{lin2023esm}. AlphaMissense predicts missense harm~\cite{cheng2023alphamissense}. DNA models extend the idea. Nucleotide Transformer shows cross-species transfer~\cite{dalla2023nucleotide}. Enformer and Borzoi learn long control~\cite{avsec2021enformer,linder2023borzoi}.

Evo scales to genome length~\cite{nguyen2024evo}. Evo2 scales further~\cite{brixi2025evo2}. It uses StripedHyena2~\cite{poli2023hyena}. It trains at 8k, then to 1M. The install pins FlashAttention-2 for efficient attention kernels~\cite{dao2023flashattention}. Rotary position ideas inform long-context handling in this class of models~\cite{su2024roformer}. Our change is deployment. We add auth, validation, calibration, and ClinVar compare. No prior demo joins all four types in one endpoint.

\section{Methods}
\subsection{Window Construction}
Let $p$ be 1-based position. Let $W=8192$. Let $L$ be chromosome length. The code fetches:
\begin{equation}
s=\max(0,p-1-W/2),\quad e=\min(L,p-1+W/2+1).
\label{eq:window}
\end{equation}
$[s,e)$ goes to UCSC. Let $w$ be the upper-case string. Let $r=p-1-s$ be offset. Fig.~\ref{fig:splice} shows four edits. The code keeps flanks equal. For deletions it centers on the midpoint.

Formally, with ALT base $a$:
\begin{equation}
w^{\text{SNV}} = w_{0:r} + a + w_{r+1:}.
\label{eq:snv}
\end{equation}
For deletion length $n$, insertion string $q$:
\begin{align}
w^{\text{DEL}} &= w_{0:r} + w_{r+n:} \label{eq:del}\\
w^{\text{INS}} &= w_{0:r+1} + q + w_{r+1:} \label{eq:ins}\\
w^{\text{DELINS}} &= w_{0:r} + q + w_{r+n:}. \label{eq:delins}
\end{align}
The UI caps $n$ and $|q|$ at 500. It rejects bad letters. It shows a reference preview from loaded sequence when able.

\subsection{Delta Score and Call}
Let $S(\cdot)$ be mean log-likelihood from \texttt{model.score\_sequences}. Then:
\begin{equation}
\Delta = S(w^{\text{var}})-S(w^{\text{ref}}).
\label{eq:delta}
\end{equation}
A negative $\Delta$ means low plausibility. The code scores ref once per unique window. It reuses the value for near variants.

Let $y=1$ for LOF and $0$ for FUNC/INT. The ROC uses $-\Delta$~\cite{hanley1982roc}. Youden's $J$ sets the point~\cite{youden1950index}:
\begin{equation}
J(t)=\text{TPR}(t)-\text{FPR}(t),\quad t^{\star}=\arg\max_t J(t).
\label{eq:youden}
\end{equation}
The stored threshold is $\tau=-t^{\star}=-0.000918$. The call is:
\begin{equation}
\text{call}=\begin{cases}
\text{Likely pathogenic}, & \Delta < \tau\\
\text{Likely benign}, & \text{otherwise.}
\end{cases}
\label{eq:call}
\end{equation}
Confidence scales by class spread:
\begin{equation}
\text{conf}=\min\!\left(1,\frac{|\Delta-\tau|}{\sigma_{\text{class}}}\right),
\label{eq:conf}
\end{equation}
with $\sigma_{\text{LOF}}=0.001514$ and $\sigma_{\text{FUNC}}=0.000902$. Fig.~\ref{fig:conf} draws this map. Far points get high confidence. Near points get low confidence. Indel types reuse SNV numbers. The response sets \texttt{provisional=true} for them.

\section{Calibration Protocol}
The BRCA1 set comes from saturation editing (Findlay et al.). The file is \texttt{41586\_2018\_461\_MOESM3\_ESM.xlsx}. The code keeps six columns. It maps FUNC and INT to one class. It keeps the first 500 rows for speed. It uses GRCh37 chr17 FASTA for windows. It dedups reference strings. It scores refs then variants. It computes AUROC on $-\Delta$. It picks $\tau$ by max $J$. It saves LOF and FUNC std values.

Fig.~\ref{fig:roc} is illustrative. It uses the reported AUROC near 0.73. It does not plot raw points. The true ROC table comes from the Modal run. Fig.~\ref{fig:strip} shows the same idea for distributions. LOF mass sits left of $\tau$. FUNC mass sits right.

\section{Results}
\subsection{Batch Check}
The 500-row run shows clear shift. Medians differ in sign side. AUROC is near 0.73. This matches published zero-shot BRCA1 skill~\cite{brixi2025evo2}. We claim no clinical use. We report one slice only.

\subsection{Live Path Example}
Query \texttt{hg38 chr17:43119628 ALT=G}. Steps:
\begin{enumerate}
\item Fetch 8192-bp UCSC window centered near $p$.
\item Read reference at $r$. Get ALT from input.
\item Score both strings with Evo2-7B.
\item Return \texttt{position, reference, alternative, delta\_score, prediction, classification\_confidence}.
\end{enumerate}
The UI shows delta to six decimals. It shows a bar for confidence from~\eqref{eq:conf}. It shows ClinVar at the same position when the title parses. It parses SNV by \texttt{A$>$G} pattern. It parses deletion, insertion, and delins by title rules. It flags indel calls as provisional. Warm latency comes from two forward passes. Cold start adds one model load.

\section{Discussion and Limits}
We state three limits. First, indel thresholds reuse SNV fit. The UI warns the user. A new indel study must refit $\tau$ and $\sigma$. Second, BRCA1 hg19 fit may not suit hg38 or other genes. Treat $\tau$ as a start point. Recalibrate per gene. Third, public APIs cap use. Search caps at 10. ClinVar caps at 20. View caps at 10\,000\,bp. Title parsing fails on odd ClinVar text. Auth adds friction but guards cost.

Future work is direct. Add indel calibration. Cache per-gene ROC. Add batch scoring. Add light auth rate limits. Deploy front end on Vercel. Log agreement with ClinVar for audit.

\section{Conclusion}
We built a full bridge. It joins genome browsers to a genome model. It covers four variant types. It uses one clear score rule. It is live and testable. It is modest in scope. It is honest on limits. Others can reuse the pipeline. They can extend it without repeat errors.
